# Raw data needed for Figure 1

Place the following files here:

- `nt_matrix.csv`
- `asd_matrix.csv`

Each file should be an image × subject matrix.

Rows: same image order across both files, expected 28 images.
Columns: subjects within each group.
Values: probability of choosing “happy”, or trial-averaged binary choice where 1 = happy and 0 = fear.

These raw matrices are not included in this repository because they were not present in the workspace used to create the package. The repository is prepared to regenerate Figure 1 once these matrices are added.
